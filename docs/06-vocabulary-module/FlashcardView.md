# FlashcardView

**Mục đích:** Hiển thị 1 `VocabularyCard` — thẻ to, emoji lớn giữa, từ tiếng Anh bên dưới, icon loa để đọc lại.
**Loại:** View
**Phụ thuộc:** nhận 1 `VocabularyCard`; gọi `SpeechService.shared.speak(card.word)` khi chạm thẻ hoặc icon loa; dùng `BigButtonStyle`.
**Trạng thái:** ☐ Chưa code · ☐ Đang code · ☐ Xong
**Ghi chú:** Chạm cả thẻ cũng đọc (không chỉ icon loa) — nhiều điểm chạm cùng 1 hành động quan trọng với bé 3-5 tuổi.
