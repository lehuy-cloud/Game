# StarsSummaryView

**Mục đích:** Tab Stars — tổng kết số sao bé đạt được theo từng chủ đề; có nút "Đổi nhân vật" mở lại `CharacterSelectionView`.
**Loại:** View
**Phụ thuộc:** đọc `progressStore.starsByCategory`; dựng từ `RewardStarsView`; mở `CharacterSelectionView` dạng `.sheet`; áp `.themedBackground()`.
**Trạng thái:** ☐ Chưa code · ☐ Đang code · ☐ Xong
**Ghi chú:** Thêm nút debug "Reset Progress" trong lúc phát triển để test lại từ đầu dễ dàng (có thể bỏ ở bản hoàn thiện, hoặc giữ vì app chỉ dùng nội bộ).
